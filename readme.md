# Soteria

Soteria est un système de gestion de PME.

## Projets

Ce dépôt est divisé en plusieurs projets pour avoir une séparation de ses fonctions (application bureau, composante web, etc.). En ce moment, Soteria compte les projets suivants:

- [`desktop`](./apps/desktop/readme.md): L'application de bureau
- [`web`](./apps/web/readme.md): La composante web
