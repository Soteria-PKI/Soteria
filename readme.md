# Soteria

Soteria est un système de gestion de PME.

## Projets

Ce dépôt est divisé en plusieurs projets afin d'avoir une division claire des fonctions principales de l'application. Présentement, ce projet comprend les projets suivants:

- [desktop](./apps/desktop/readme.md): L'application de bureau
- [web](./apps/web/readme.md): La composante web
